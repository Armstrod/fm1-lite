    MIDI file

    Open a .mid from this phone. It's split onto the FM-1's four parts (STABS, BASS, LEAD, DRUMS) and played through the firmware that's on, with its own sounds: switch the firmware on first, and leave its own sequencer stopped. The file stays on the phone.

    Your firmware repo

    FM-1 Lite looks through this GitHub repository for .wasm files (each in its own folder, with an optional firmware.json) and lists them, checking again each time the app opens. A private repository needs a token: a fine-grained one, for this repository only, with Contents: read. It stays on this phone.

    FM-1 Lite plays each firmware's own browser build, fetched from its author's site. Firmwares are by their authors under their own licences: see each one's source.
